# Netflix_analysis-Project

This project explores Netflix's movies and TV shows catalog using Python, PostgreSQL, and Power BI. The objective is to transform raw data into meaningful insights and present them through an interactive dashboard.

--Project Objectives

Analyze the distribution of movies and TV shows.

Identify the most common genres.

Explore content distribution across countries.

Examine release-year trends.

Understand the distribution of content ratings.

Build an interactive dashboard for exploring the Netflix catalog.

--Tools and Technologies

Python: Data cleaning and exploratory data analysis

Pandas: Data manipulation and preprocessing

PostgreSQL: SQL querying and analysis

Power BI: Interactive dashboard and data visualization
